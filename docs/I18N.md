# Internationalization (i18n)

AIKit localizes user-facing strings on a **per-component** basis using `@gravity-ui/i18n`. Each component bundles its own keyset and reads the language of the nearest UIKit `Provider` or `LangProvider`.

Out-of-the-box languages: **English (`en`)** and **Russian (`ru`)**.

## How It Works

Each localized component contains an `i18n/` directory:

```
ComponentName/
├── i18n/
│   ├── index.ts      # registers the keyset with @gravity-ui/i18n
│   ├── en.json
│   └── ru.json
```

The keyset is registered under a namespace derived from the component's name. Components and hooks call the keyset's `useTranslation()` hook. Its translator follows the nearest UIKit language context and updates when that context changes, including strings cached with `useMemo` or `useCallback`.

## Setting the Language

```tsx
import {LangProvider, Provider} from '@gravity-ui/uikit';

<Provider lang="ru">
  <ChatContainer onSendMessage={handleSendMessage} />
  <LangProvider lang="en">
    <HistoryList chats={chats} />
  </LangProvider>
</Provider>;
```

Pass your language state to `Provider.lang` to update the application without a global configuration mutation. `LangProvider` overrides only the language of a subtree, so independent chats can display different languages at the same time.

For an application-wide default without an explicit language prop, UIKit's `configure({lang: 'ru'})` remains available at bootstrap. Import it from `@gravity-ui/uikit`.

## Overriding Strings

Every component that has user-visible text also exposes a `texts` prop (or per-feature prop like `headerProps.texts`) for per-instance overrides. `ChatContainer` aggregates these via a single `texts` prop on the page level. The resolution order is:

1. `texts.<key>` on the component (or on `ChatContainer`)
2. Custom keyset registered with `@gravity-ui/i18n` (if you override the bundled one)
3. AIKit's bundled `i18n/<lang>.json` defaults

## Adding a Custom Language

Re-register the bundled keysets with your translations:

```tsx
import {Provider} from '@gravity-ui/uikit';
import {addComponentKeysets} from '@gravity-ui/uikit/i18n';
import esHistory from './my-translations/History.es.json';

addComponentKeysets({es: esHistory}, 'g-aikit-History');

<Provider lang="es" fallbackLang="en">
  <App />
</Provider>;
```

Namespace prefixes match the component name (e.g. `g-aikit-Header`, `g-aikit-MessageList`). Inspect `src/components/.../i18n/index.ts` for the exact key.

## Localized Components

22 components ship with built-in translations:

### Atoms

- `ChatDate`
- `SubmitButton`

### Molecules

- `ActionPopup`, `BaseMessage`, `FeedbackForm`, `FileDropZone`, `FileItem`, `InputContext`,
- `PromptInputFooter`, `StarRating`, `Tabs`, `ToolStatus`

### Organisms

- `AttachmentPicker`, `FileUploadDialog`, `Header`, `MessageList`, `ThinkingMessage`, `ToolMessage`

### Templates

- `EmptyContainer`, `History`

### Pages

- `AIStudioChat`, `ChatContainer`

Components not listed above either have no visible text or take all text through props.
